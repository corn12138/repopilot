# 证据页下面还挂着发射台

交互评审 v0.2（docs/inception 本地）真机走查抓到的 N1，是个真 bug 不是密度问题：
打开证据页时，上一个选中 Run 的 ChatHead、审批停靠条、Composer 仍然渲染在
证据内容的上下方 —— **在证据页里能勾披露、点「开始」发任务，停靠条上能批准计划**。

## 根因

主栏内容区的视图分发是完整的（`showEvidence → showSettings → RunDetail → …` 链式三元），
但主栏的三个"伴随件"各自带守卫，且守卫只判了一半：

```tsx
{!showSettings && selectedRun && <ChatHead …>}
{!showSettings && selectedRun && … && <ApprovalDock …>}
{!showSettings && selectedProject && … && <Composer …>}
```

设置页是后来才有的全屏视图，加它的时候顺手给三处配了 `!showSettings`；
证据页更晚，没人回来补。典型的"守卫散落在使用点、没有单一事实源"。

## 修复

派生一个语义变量，四处（含离底新事件提示）统一：

```tsx
// 设置与证据都是全屏视图：选中 Run 的顶栏/新事件提示/审批停靠条/Composer 一律让位。
const fullScreenView = showSettings || showEvidence;
```
