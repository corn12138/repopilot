# 全局状态只有一个家

交互评审 v0.1 #9 / v0.2 P1：全局状态此前散落三个角落 —— Core 状态在侧栏顶部小字、
模型配置状况在 composer 右下与设置按钮的 ⚠、预算只在 Run 详情。IDE 的惯例是
底部状态栏：一条 26px 的安静横条，横跨所有列，是全局事实的唯一权威位。

## 改了什么

- `.app` 增加第二行 grid row，状态栏 `grid-column: 1 / -1` 横跨侧栏/对话/编辑器。
- 栏内内容（左→右）：Core 状态点+文字 · 当前项目名（title 带完整路径）·
  运行中 N（仅 >0 时）｜右端：选中 Run 的预算水位（仅非终态，title 带精确分子分母、
  "超限即停不重置"）· 模型可用数（可点，直达设置页；未配置时文案是「未配置模型」）。
- **唯一主场执行**：侧栏顶部小字不再重复 Core 状态（改为固定的 `prototype ·
  disposable spike`）。设置按钮的 ⚠ 保留 —— 那是行动提示，不是状态陈列。
- 没放进去的：v0.1 设想的「冻结路由」。Run 的路由事实在事件流里，状态栏放它
  需要新的投影通道 —— 不为一行小字加 IPC，等有真实需要再议。
