# 键盘不欠一等

交互评审 v0.1 #11 / v0.2 P2。「主流程可全键盘完成、无 trap、焦点可预测」是
PRD-NFR-ACC-001 冻结的 P0 需求，不是新功能 —— 此前全局快捷键为零，
只有 4 处局部键位。这一片把贯通补上。

## 改了什么

- **Esc 关层**：设置/证据是"层"，Esc 退回之前的运行/项目视图。v0.1 病根 B
  记录过它们"只进不出"—— 现在键盘有了出口（面板自己的 Esc 各自先处理，
  命令面板与任务选项弹层不受影响）。
- **F6 / Shift+F6 面板循环**：侧栏 → 主栏 → 编辑器（存在时）循环聚焦，
  落点是该区域第一个可聚焦控件。区域列表从 DOM 现查，不维护镜像。
- **树内方向键**：↑↓ 在可见行间移动，→ 展开目录（已展开则进入下一项），
  ← 收起目录（文件/已收起则回父级）。行身份放在 `data-path` / `data-dir` /
  `aria-expanded` 上 —— 键盘导航读 DOM 事实。目录行顺带补上了
  `aria-expanded`（此前展开状态对辅助技术不可见）。
- **侧栏列表方向键**：↑↓ 在项目/Run 行间移动；折叠区（`details:not([open])`）
  里的行不参与 —— 焦点不进用户看不见的地方。

## 测试

树：↑↓ 移动 → 子项 ← 回父级 ← 收起（app.ts 离屏 + aria-expanded=false）→
重新展开。App：Esc 从设置层退回；F6 依次进侧栏/主栏、Shift+F6 反向。
