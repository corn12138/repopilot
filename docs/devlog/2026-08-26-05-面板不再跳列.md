# 面板不再跳列

交互评审 v0.2 P1 骨架层第一片。此前的布局有四种形态，且互相切换时面板会换列换宽
（N12）：文件树平时在最右 340px，编辑器一打开就跳到左二列缩成 280px，对话被挤到
最右。IDE 的空间反射建立在「面板位置恒定」上 —— 这一片把四种形态收敛成两种：

```
默认        侧栏 264px │ 对话
编辑器打开   侧栏 264px │ 对话 │ 编辑器
```

## 改了什么

### 文件树入左栏 Activity（v0.1 #8 / v0.2 §5.2）

侧栏顶部新增「运行 ⇄ 文件」切换：树的惯例位在左（VS Code/Cursor 反射），
一次只有一个关注点。底部的「🗂 文件」按钮退役 —— 它的禁用态与原因提示
（先导入项目 / 证据损坏）原样搬到「文件」标签上。树接管侧栏时运行列表让位，
✕ 或点「运行」标签回来。

### 对话恒居中，编辑器恒右舞台（v0.2 §5.2 IA 修订落地）

编辑器打开时对话不再被挤到最右 —— 使用者的主要时间在看时间线、做决定，
代码是「点进去核验的证据」。编辑器永远出现在右舞台，grid-column 全显式指定。
`with-files` 四栏形态整体退役（CSS 规则删除，布局测试钉住它不复活）。

### 编辑器显式收起（N12 的"显式开关"）

标签条右端新增 ⇥ 收起：编辑器列让位、**标签保留**；主栏顶部出现一条安静的
回程条「编辑器已收起 · N 个标签 —— 点击展开」。打开任何文件也会自动展开 ——
"打开文件"就是"我要看编辑器"的显式表达。tablist 语义顺带修正：
role=tablist 里现在只有标签，收起按钮在条末的 tablist 之外。

## 测试

`App.layout.test.tsx` 钉住整条链：文件标签禁用态与原因 → 导入后可用 →
树接管侧栏（运行列表让位）→ 双击文件进入 `ide` 三栏 → 收起后 `ide` 消失、
回程条报标签数 → 展开恢复 → 切回运行视图。并断言 `with-files` 类不再出现。

真机走查：docs 项目 → 文件视图 → 双击 ADR 文档 → 三栏成形（对话居中）→
⇥ 收起 → 回程条 → 展开，全链路截图核对。
