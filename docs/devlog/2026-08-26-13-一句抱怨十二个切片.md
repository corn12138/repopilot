# 一句抱怨，十二个切片

用户在真机上用了两天，反馈只有一句：「信息既密集又难用」。两天后，这句话变成了
12 个提交、renderer 侧 21 个文件 +2712/-626 行、测试从 1035 涨到 1061 ——
而且没有删掉任何一条事实。这篇记录这一轮怎么走的、顺序为什么是这个顺序、以及三条差点
溜过去的假绿。逐个切片的细节在 08-26-01 到 08-26-12，这里只写弧线。

## 问题是什么

「密集又难用」是体感，不能直接开工。先做了两件事把它变成可执行清单：

1. **真机走查**：用 CDP 驱动当前构建，以使用者身份截了六个界面。逐条数下来，
   病根不是"事实太多"（这个产品的存在理由就是不删事实），是三个机制：
   **同一事实没有唯一主场**（状态徽章三处、用量三处、出站账本两处）、
   **审计语态对着操作者说话**（中文句子里裸嵌 `ACCEPTED_UNVERIFIED`，证据页
   开头引用 PRD 编号）、**设计内常态被渲染成常开警报**（恢复的 Run 永远顶着
   黄条，文件面板永远红字报错）。
2. **落档成评审**（交互评审 v0.2，本地）：新发现编号 N1–N12，与 v0.1 的
   #1–#13 对齐；用户拍板对标方向 ——「像 Claude Code，先模仿再超越」。

## 顺序为什么是这个顺序

v0.1 定过修复次序：**先降噪（不动骨架）→ 再分工（动骨架）→ 后反射（加全局操作）**。
这一轮完整走完了它：

| 层 | 切片 | 一句话 |
|---|---|---|
| 即刻 | 01 | 证据页守卫 bug：全屏视图下还能发任务、批准计划 |
| P0.5 降噪 | 02–04 | 每个事实一个主场 · 一本词典说到底 · 出口放在数据所在之处 |
| P1 分工 | 05–08 | 面板不再跳列 · 状态栏 · 预览通道合一 · 分隔线记宽度 |
| P2 反射 | 09–12 | 相位锚点+终端上限 · ⌘K · 键盘贯通 · diff 也是一种标签 |

顺序不是美学偏好，是风险控制：降噪层零骨架改动，错了随时回退；骨架层
（Activity 左栏、对话恒居中）动 grid，但此时列表层已经安静，回归可辨认；
反射层（⌘K、F6、方向键）全是增量，压在稳定的骨架上。十二片全程零 Core /
零 IPC 改动 —— 交互问题在呈现层解决，权威层一行没碰。

## 踩了什么坑

**坑一：测试和实现互相印证成假绿（两次）。**
轮次行的 token 计量收进 title 用了正则 `\((in=…)\)` —— 半角括号。测试构造的
事件也用半角括号，双双通过。真机一看：Core 的真实 summary 是**全角**
`（in=…）`，这条降噪从未生效过。同类问题上一轮也出过一次（jsdom 无布局，
勾选框破版 105 条测试全放行）。结论一样：**夹具的字面量要抄真实数据，
不要抄实现的想象**；能上真机就上真机。

**坑二：`beforeEach(() => mock.mockReset())` 会被 vitest 当 teardown。**
`mockReset()` 返回 mock 本身，vitest 把 beforeEach 的返回值当清理回调，
测试结束时**零参调用了 mock**——报错 `Unexpected request: undefined`，
栈指向 `callCleanupHooks`。修法是加大括号吞掉返回值。这种坑值得写在
测试文件的注释里，因为下一个人一定还会这么写。

**坑三：自己写的评审自己打架。**
v0.2 §5.2 写「编辑器/文件/证据恒右舞台」，P1 计划行却抄了 v0.1 的
「Activity 化左栏」——文件树到底在左还是在右，两处矛盾。实现时才发现，
按 IDE 反射拍板（树在左，编辑器在右，证据全屏）并回改了文档。
**计划文档也需要一致性检查，尤其是修订别人的（哪怕"别人"是昨天的自己）。**

另有一条正向记录：styles 合同测试真的逮住了一次退役 token 复活
（`--text-faint`），门禁不是摆设。

## 可复用的结论

- **「折叠 + 报数 = 合规省略」是万能钥匙，但报数本身也要守音量** ——
  解释省略了 2 条事件的披露段曾经有四行长。报数一行，明细点开。
- **每个事实只有一个主场**。密不是因为信息多，是同一事实被说了两三遍。
  修法从来不是删，是给每个事实指定唯一的层级归属。
- **设计内状态不许穿警报的衣服**。恢复的 Run 落后一拍、工作区已回收 ——
  这些是正常终局，渲染成黄条红字，真警报就失去信号价值（狼来了）。
- **词典要么贯彻要么没有**。映射表存在但句子里裸写枚举，等于让读者
  每句话切一次语言。红线一句话：用户可见文本只用词典词，raw 进 title。
- **布局稳定先于布局可调**。面板不跳列（骨架）在前，分隔线可拖（偏好）
  在后 —— 顺序反了，用户调的是一个会自己变形的东西。

## 还挂着的

代码层面评审四层已清空。剩两件明确不属于呈现层切片的：N11 决定摩擦分级
（要写进冻结的设计基线，需单独评审）、选择性归档（需要 Core 新概念，
retention 只按天龄）。设计侧的批 4（light 主题）与批 V（表达层换皮）不在
本轮范围。下一轮的输入应该是**真实使用**：四层落完之后哪里还硌手，
比任何启发式走查都值钱。
