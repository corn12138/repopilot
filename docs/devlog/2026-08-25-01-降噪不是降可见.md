# 降噪，不是降可见

交互评审（08-25，docs/inception 本地）定了病根：「工程诚实」被实现成了「全音量」——
所有事实、所有时刻、同等音量。P0 这一片按评审动手，改四处，原则一条不破：
**每一处都是降层级，不是删事实**。自家规矩本来就给了出路：省略要报数 ⇒ 折叠 + 报数 = 合规。

## 改了什么

### 1. Run 行：两枚徽章 → 状态点 + 标题 + 相对时间

原来每行 = 状态徽章 + 证据徽章（"状态落后于事件"）+ 标题。证据徽章是**元数据的层级错位**：
`EVENTS_AHEAD` 描述的是持久化证据的完整性，它属于详情页的证据栏，不属于列表层每行喊一嗓子。
真机里 8 条 selftest 残留 × 2 枚红黄徽章 = 满屏警报，真正要找的 Run 反而淹没。

现在：
- 行内一个 7px 状态点 + 标题 + 相对时间（超 7 天给日期，不给"3 周前"这种要心算的）；
- 证据徽章**移居**详情页头部（ChatHead），行内保留在 tooltip 与 aria-label —— 移动，不是删除；
- 待人决定的状态（AWAITING_*）额外带「待你决定」文字 chip：等用户的东西不允许只靠颜色。

**状态点是色 + 形双编码**（PRD-NFR-ACC-001 冻结过"状态不能只依赖颜色"）：
成功/进行中实心圆、失败类实心方、中断类空心圆。色盲用户靠形状就能分开成败。

### 2. 历史折叠：每项目只展开进行中 + 最近 5 条终态

更早的收进「更早的 N 条 ▸」。selftest 残留全部落进折叠区 —— 数量如实报着，
但不再刷屏。真删除的入口在设置页的保留策略（sweep），本来就有。

### 3. 项目首屏：审计报告 → 摘要 + 两个折叠区

徽章行（是什么/多大/几个命令）保留为首屏摘要；其下：
- **「注意事项（N）」**：四类警告横幅（未跟踪 / 形态排除 / 枚举截断 / 非干净基线）
  合并进一个折叠条，原文一字不少。**含 err 级（LFS、截断）时默认展开** ——
  必须处理的事不许被收起来藏住；
- **「导入详情 · base xxx · N 个命令」**：digest / 检测信号 / 命令映射 / 排除清单 /
  导入范围选择，整体收进折叠区。它是导入审计报告，点进去看，不再当首屏。

### 4. 顺带

`runStatusTone` 从 RunStatusBadge 里抽出（一处定义、徽章与状态点两处消费 —— 复制会漂移）；
`relativeTime` 带边界单测（未来时间戳按"刚刚"，解析失败给空串不渲染 NaN）。

## 踩了什么坑

### tooltip 语义变了，测试用 getByTitle 精确匹配全红

行的 title 原来就是标题本身，现在有意携带「状态｜证据｜标题」——
这是徽章撤下后信息的去处之一。五处 `findByTitle('Run A')` 全部失配。
按"改了行为就同步改断言"处理：换成后缀正则匹配。断言红得其所 ——
它证明 tooltip 确实变了，而这正是这次改动想要的。

### CSS 选择器猜了个不存在的类

`.import-details > .subpkg` —— SubPackagePicker 的根类其实是 `field`。
样式选择器不会报错，只会静默不生效；写完当场 grep 验证类名，别信记忆。

## 可复用的结论

- **元数据要住在自己的层级里。** 证据完整性属于详情页，不属于列表；
  把所有真话在所有层级重复一遍，等于每句都没人听。
- **折叠的展开默认值是个语义决定。** err 级默认展开、warn 级默认收起 ——
  折叠条自己要会分轻重，否则"折叠"就变成了"藏"。
- **降噪的每一步都要能回答"信息去哪了"。** 徽章 → 详情页 + tooltip + aria；
  横幅 → 折叠区原文；历史 → 报数的折叠。答不出去向的降噪就是删除。
